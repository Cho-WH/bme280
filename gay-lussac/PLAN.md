# 게이뤼삭 실험 초보자 모드 초기 버전 기획안

밀폐한 기체의 온도와 압력을 측정하는 실험을 **3D 장치 준비 → 공식 도구로 프로그램 전송 → 측정 → 브라우저 저장 → 학생 주도 분석**으로 연결한다. 장치 준비는 자세히 돕고, 측정 안내는 최소한으로 제공한다. 분석은 학생이 표와 도구를 자유롭게 조작하는 작업 공간으로 만든다.

구체적인 화면·상태 전환·모듈 계약과 구현 순서는 [초보자 모드 구현 설계](DESIGN.md)에서 이어진다.

모듈의 소유권·의존 방향과 도입할 도구는 [구현 경계와 라이브러리 선택](ARCHITECTURE.md)을 기준으로 한다.

## 2 사용자 흐름과 공통 화면

### 2.1 시작 화면

제목은 **기체의 온도와 압력**, 소개는 “밀폐한 공기를 데우면 압력은 어떻게 달라질까요?”로 둔다. 기본 진입은 **처음부터 준비하기**이며, **장치가 준비되어 있어요**, **저장된 실험 열기**를 함께 제공한다.

장치가 준비된 사용자는 상세 조립·전송 설명을 건너뛰고 실제 수신 확인부터 시작한다. 저장된 실험은 Bluetooth 연결 없이 분석할 수 있다. 중급자 모드의 선택 UI는 후속 버전에 추가한다.

### 2.2 화면 전환

| 화면 | 중심 내용 | 주요 행동 | 다음 상태의 근거 |
|---|---|---|---|
| 장치 준비 | 3D 모델, 현재 연결할 부분, 짧은 설명 | 연결했어요 / USB로 프로그램 설치 / 수신 확인하기 | 물리적 조작은 사용자 확인, 전송은 공식 API 완료, 수신은 실제 데이터로 확인 |
| 측정 | 온도·압력과 시간 그래프 | 가열 시작 / 물 추가 / 장치 변화 / 측정 마치기 | 실제 수신·저장 상태와 사용자의 조작 기록 |
| 분석 | 표, 분석 도구, 그래프 | 자료 선택 / 계산 열 / 그래프 / 직선 맞추기 / 내보내기 | 학생의 선택과 계산 결과 |

준비·측정·분석과 USB 설치는 같은 앱의 화면으로 구성한다. 정적 호스팅에 맞춰 해시 라우팅을 사용하고, 예를 들어 `#/analysis?run=<id>`는 IndexedDB의 해당 실험을 연다.

M2에서는 원자료를 페이지 구분 없이 스크롤하며 읽고 전체 CSV를 내보낼 수 있다. 계산·그래프 만들기·회귀는 M3에서 활성화한다. 준비 단계 바를 건너뛰어도 기록은 첫 수신부터 남지만, **가열 시작**은 용기 배치 확인과 최근 유효값 3개·1초 확인 이후에만 사용할 수 있다. 직접 측정 화면으로 왔다면 **용기를 배치했어요**로 확인한다.

- 제목과 도움말 위치를 유지하고, 준비의 3D 모델에서 측정의 그래프로 중심을 옮긴다.
- 이전 설명을 다시 열어도 연결과 측정 기록은 유지한다.
- 분석으로 들어가면 준비 단계의 진행바를 분석용 강제 순서로 이어 붙이지 않는다.
- 주요 행동은 글자로 표시한다. 색상과 아이콘은 상태를 보조한다.
- 측정 중 정상적인 저장 상태는 **자동 저장 중**으로 유지해 짧은 상태 전환이 시선을 방해하지 않게 한다. 저장 오류는 즉시 구분하고, 측정 종료 후 실제 저장 완료를 표시한다.
- 노트북에서는 표·그래프를 함께 보고, 작은 화면에서는 표/그래프를 전환한다. 작은 화면에서도 데이터와 선택 상태는 동일하게 유지한다.

## 3 3D 장치 준비와 공식 USB 전송

### 3.1 준비 단계

| 순서 | 3D 또는 안내의 초점 | 사용자가 할 일 |
|---|---|---|
| 1 | 전체 장치와 준비물 | 센서·확장 보드·micro:bit·케이블·배터리·용기·수조·고정 장치를 확인한다. |
| 2 | 배선별 양쪽 단자 | 기존 모델의 배선 강조로 한 선씩 연결한다. 핀 이름을 색상과 함께 읽는다. |
| 3 | micro:bit의 USB 포트 | 노트북과 데이터 전송 가능한 USB 케이블로 연결한다. |
| 4 | 노트북과 전송 안내 | 앱의 설치 버튼으로 준비된 실험 프로그램을 USB 전송한다. |
| 5 | 장치 이름과 실제 값 | 같은 화면에서 Bluetooth를 연결하고 새 온도·압력값을 확인한다. |
| 6 | 배터리와 USB 분리 | 배터리 전원으로 전환하고 USB를 분리한 상태에서 새 값이 들어오는지 확인한다. |
| 7 | 용기 내부와 수조 | micro:bit·확장 보드와 배터리는 용기 바닥에, 센서는 중간 높이의 공기 중에 배치한다. USB를 분리하고 모든 배선을 용기 안에 넣어 밀폐한다. 외부에서 용기를 지지해 자세와 침수 깊이를 유지한 뒤 **배치했어요**로 확인한다. |

현재 단계가 시작되면 관련 부분을 확대하고 사용자가 조작하는 동안 시점을 유지한다. 자유롭게 돌려 본 뒤 **↺ 시점 초기화**로 복귀할 수 있다. 모델에서 선을 표시한 상태와 실제 연결 확인 상태를 구분한다.

기존 모델의 USB·배터리 단자와 배선 기능을 재사용한다. 수조·용기 배치는 초기에는 간단한 전체 그림과 필요한 부분의 3D 표현으로 안내한다. 노트북 전체를 정밀하게 모델링하는 작업은 요구하지 않는다. WebGL을 사용할 수 없는 경우 같은 순서의 정지 그림과 연결표를 제공한다.

준비 그림의 보조 도구는 상단에 모으고 하단 띠와 회전·확대 힌트는 생략한다. 준비물·배선에서는 **3D 보기 / 배선표 보기**로 전환하며 배선표는 연결할 핀과 현재 단계를 간결하게 보여 준다. 용기 배치 그림에는 3D 도구를 표시하지 않는다.

보기 전환 시 그림 영역은 유지하고, 배선 네 단계 사이에서만 설명 길이에 따른 완료 버튼 이동을 막는다. 다른 단계의 완료 버튼은 내용 가까이에 둔다. 불러오기 문구는 별도 줄을 차지하지 않으며 내부 스크롤을 만들지 않는다. 단계 바의 선택 표시는 옆으로 미끄러지고 오른쪽 설명은 짧은 슬라이드로 등장한다. 모델에는 페이드를 적용하지 않으며 동작 줄이기 설정을 존중한다.

### 3.2 공식 USB 도구 사용 경로

공식 구현: **[micro:bit connection library](https://microbit-foundation.github.io/microbit-connection/)**. USB·HEX 처리 부분만 고정한 로컬 번들로 포함하고 얇은 어댑터에서 호출한다. 준비된 파일을 앱 안에서 자동 전송하는 것이 D1의 사용자 의도다. 별도 공식 웹사이트를 iframe으로 포함하거나 자체 플래싱 엔진을 만들지 않는다. [S9]

1. 앱이 지정된 HEX를 미리 읽고 SHA-256과 V2용 내용을 확인한다. 파일명·버전과 **USB로 프로그램 설치**를 표시한다.
2. 버튼을 누르면 공식 라이브러리가 USB 연결을 시작한다. 처음에는 브라우저 장치 선택 창에서 micro:bit를 선택한다.
3. V2임을 확인하고 기존 Bluetooth 연결을 정리한 뒤 전체 프로그램을 전송한다. 진행률을 같은 화면에 표시한다.
4. 공식 API가 성공으로 끝난 뒤 설치 성공 안내와 **설치했어요** 버튼을 표시하고 USB 인터페이스 점유를 해제한다.
5. Bluetooth로 새로운 온도·압력이 수신되는지 확인한다. 이후 배터리 전원 상태에서도 수신을 확인한다.

다운로드 폴더·파일 선택·외부 탭 이동 없이 설치한다. USB 연결만으로 최초 권한이 생기지는 않는다. 같은 페이지에서 선택한 장치의 재설치는 한 번의 클릭으로 시작하며, 새로고침·장치 교체·권한 상태에 따라 선택 창이 다시 열릴 수 있다. 이미 설치된 장치는 명시적인 **이미 프로그램이 있어요 · 수신 확인**으로 진행할 수 있다.

> [!NOTE]
> 여기서 넣는 것은 **실험용 응용 프로그램**이다. micro:bit의 USB 인터페이스용 DAPLink 펌웨어 업데이트는 필요한 장치의 문제 해결에서 별도로 안내한다. 학생 화면에는 **실험 프로그램 넣기**라고 표시한다. [S4]

### 3.3 확인 가능한 상태

- 설치 버튼 클릭·진행률 100%만으로 성공을 판정하지 않는다. 공식 `flash()` 완료 응답이 근거다.
- 취소·연결 실패·USB 분리·전송 오류는 성공과 구분한다. 설치 중 중복 전송과 새 Bluetooth 연결을 막고, 성공·실패 모두 USB 인터페이스를 해제한다.
- 초기 작동 확인 후보는 **1초 이상에 걸친 유효 샘플 3개 이상 수신**이다. 한 통신 패킷에 몰려 들어온 값만으로 확인을 끝내지 않는다. 이 조건은 통신 경로 확인용이며 센서 정확도나 프로그램 버전 증명이 아니다.
- Bluetooth 검색은 사용자의 연결 버튼으로 시작한다. USB 장치 선택과 Bluetooth 장치 선택을 각각 해당 단계에서 안내한다. [S5]
- 배터리 전환 후에도 마지막 숫자의 잔상이 아닌 **새로운 수신 시각**을 확인한다.
- 연결 실패 도움말은 **장치가 목록에 없어요 / 전송이 안 돼요 / 연결했는데 값이 없어요 / USB를 빼면 멈춰요**로 구성한다.

기준 HEX는 현재 `firmware/bme_1.2.hex`를 출발점으로 검토한다. 실제 BMP280 모듈·배선·micro:bit V2에서 동작과 출력 형식을 확인한 파일만 기준 프로그램으로 지정한다. 파일 경로·버전·해시·센서 프로파일을 하나의 설정으로 관리한다.

## 4 최소 측정 안내

### 4.1 측정 화면

| 영역 | 초기 제공 내용 |
|---|---|
| 상단 | 연결 상태, 수신 상태, 저장 상태, 경과 시간 |
| 주요 숫자 | 온도 `℃`, 용기 안 압력 `hPa` |
| 시간 그래프 | 같은 시간축을 사용하는 온도·압력 그래프. 기본은 최근 60초이며 전체 구간 보기 제공 |
| 현재 안내 | 지금 할 일 한 문장, 필요한 경우 짧은 확인 사항 |
| 조작 버튼 | 가열 시작, 물 추가, 장치 변화, 측정 마치기 |
| 도움말 | 장치 배치와 연결 설명 다시 보기 |

최근 60초는 **수신 시각**으로 계산한다. 명목 샘플링 주기만으로 600개를 항상 1분으로 취급하지 않는다. 표시 구간이 바뀌어도 전체 기록을 보존한다.

### 4.2 최소 안내 상태

| 안내 상태 | 기본 문구 | 동작 |
|---|---|---|
| 배치와 시작 상태 확인 | “용기를 고정하고 온도와 압력의 변화를 잠시 살펴보세요.” | 준비 구간을 보존한다. |
| 가열 시작 | “준비되면 가열을 시작하고 버튼을 눌러 주세요.” | `heating-start` 사건을 기록한다. |
| 변화 관찰 | “온도와 압력이 어떻게 변하는지 관찰해 보세요.” | 물 추가·장치 변화 시각을 한 번의 클릭으로 기록한다. |
| 측정 종료 | “측정을 마치면 기록을 저장하고 분석할 수 있어요.” | 마지막 자료 저장을 완료한 뒤 분석 화면을 연다. |

**기록 일시정지 / 기록 재개**를 측정 마치기와 별도로 제공한다. 일시정지 중에도 Bluetooth 연결과 현재 값 미리보기는 유지하지만 새 값은 저장·그래프에 추가하지 않는다. 정지·재개 시각을 남기며, 재개 후 새 구간을 시작해 공백을 선으로 잇지 않는다. 물 추가·장치 변화 메모는 정지 중에도 남길 수 있다.

측정을 마친 실험에는 **추가 측정**을 표시한다. 용기·기체 부피, 밀폐·뚜껑 개방, 센서·배선·설정의 변경 여부를 팝업 체크리스트로 확인하고 같은 실험의 새 구간에 기록한다. 변경·불확실 조건은 메모를 남긴 뒤 이어갈 수 있으며 새 실험 분리를 권한다. 기존 자료와 분석 작업을 보존하고 배치·가열 확인을 새로 받는다. 분석 화면 이동은 기록을 자동 정지하지 않는다. M3에서는 추가 자료를 **새 자료 보기**로 표에 불러온 뒤 **선택 자료 적용 / 전체 자료 적용**으로 명시적으로 분석에 반영한다. 표 갱신만으로 기존 분석 범위를 늘리지 않는다.

안내 문구·적용 상태·추천 행동은 단계 정의로 관리한다. 최초 수신부터 준비 구간으로 자료를 보존하고, 가열 시작은 별도의 시각 표시로 남긴다. 사용자가 기록 시작 버튼을 따로 챙기지 않아도 되는 흐름으로 구성한다.

초기 버전에서는 특정 온도 도달, 고정 대기시간, 목표 물 투입량으로 단계를 강제 진행하지 않는다. 가열 조건은 검증한 장치의 운영 안내로 나중에 보완한다.

**물 추가**는 시각을 바로 남긴다. **장치 변화**에서는 장치 이동·뚜껑 열림·다시 밀폐를 선택하고 짧은 메모를 덧붙일 수 있다. 상세량 입력은 측정 흐름을 막지 않는다. 나중에 사건의 시각·내용을 수정하면 사용자 수정 기록으로 남긴다.

## 5 실시간 상태 확인과 누설 의심 안내

### 5.1 기본 구현

| 규칙 | 판단 근거 | 사용자 표시 |
|---|---|---|
| 수신 중 | 새 유효 샘플의 도착 시각 | “측정값을 기록하고 있어요.” |
| 수신 중단 | Bluetooth 해제 또는 일정 시간 새 유효 샘플 없음 | “측정값 수신이 멈췄어요. 연결을 확인해 주세요.” |
| 누설 의심 | 가열 중 충분한 온도 상승에 비해 압력 반응이 지속해서 작음 | “온도가 오른 것에 비해 압력 변화가 작아요. 용기 누설 가능성이 있어요.” |

누설 의심 안내에 **상태 확인**을 제공하고, 펼치면 “기체와 센서의 온도 차이 등 다른 원인도 있을 수 있어요. 뚜껑을 열거나 장치가 움직인 일이 있었는지 확인해 보세요.”를 보여준다.

수신 중단과 저장 오류는 누설 의심보다 먼저 표시한다. 조건이 부족한 동안에는 **추세를 살펴보는 중**으로 두며, 안내가 없다는 이유로 밀폐 성공이나 실험 정확성을 판정하지 않는다.

점검 모듈은 관측 상태와 근거를 반환한다. 원자료·분석 구간·기록 진행 여부는 변경하지 않는다. 같은 상황을 반복 팝업으로 알리지 않고 상태가 변할 때 갱신한다. 경고는 그래프 확인과 기록을 계속할 수 있는 영역에 표시한다.

### 5.2 온도 대비 압력 반응 계산

밀폐된 일정 부피 기체의 단순 모형에서 `P = kT`를 비교 기준으로 사용한다. 여기서 압력은 절대압, `T`는 절대온도(K)이다. 다음은 **점검용 휴리스틱 설계**이며 누설을 검증하는 방법이나 누설률 측정식이 아니다.

1. 용기 배치를 완료한 뒤의 연속 유효 자료에서 기준값 `P₀`, `T₀`를 얻고 `k₀ = P₀ / T₀`를 보존한다. 기준값을 얻었다는 사실은 열평형 판정이 아니다.
2. 사용자가 가열 시작을 기록한 뒤, 충분한 길이의 연속 시간창을 모은다.
3. 창의 앞쪽과 뒤쪽 소구간에서 각각 온도·압력 중앙값을 구하고 `ΔT`, `ΔP`를 계산한다.
4. `ΔT`가 설정한 최소 상승폭 이상인 경우에만 `r = ΔP / (k₀ × ΔT)`를 계산한다.
5. `r`이 설정한 비율보다 작은 상태가 일정 시간 지속되면 한 번 안내한다.

BMP280의 표시 온도는 기판 온도·자체 발열·주변 온도의 영향을 받는다. 이 때문에 열적 상태 차이도 작은 압력 반응처럼 보일 수 있다. `r`은 관찰 구간의 압력 반응을 비교하는 값으로만 사용한다. [S6]

- 파싱 가능한 범위 밖 수치는 샘플 ID와 유효성 표시를 붙여 원값 그대로 보존하고 점검 계산에서 제외한다. 파싱할 수 없는 수신은 발생 시각과 오류 종류를 사건으로 남긴다.
- 준비 구간이 부족하면 가열 시작 이후 처음 확보한 연속 구간으로 기준값을 정할 수 있다. 사용한 구간을 기록하며, 이미 발생한 누설을 배제하는 근거로 삼지 않는다.
- 알려진 장치 이동·뚜껑 열림은 계산을 재시작할 단서로 사용한다. 뚜껑을 열었다는 기록 뒤에는 재밀폐 확인 후 새 기준 구간을 모은다. 단순 물 추가는 계속 가열하는 조작으로 기록한다.
- 해제 조건을 평가할 수 없게 되면 ‘현재 판정 보류’로 표시한다. 과거 경고를 숨기고 정상 상태라고 표시하지 않는다.
- 저장된 수치가 같아도 새 유효 샘플이 도착하고 있으면 수신 중이다. 센서 해상도 때문에 같은 값이 반복될 수 있다.
- 점검 결과에는 규칙 버전, 근거 시간창, `P₀/T₀`, `ΔT`, `ΔP`, `r`, 상태 전환 시각을 저장한다. 학생에게 숫자 전체를 기본 표시할 필요는 없다.

## 6 브라우저 저장과 측정 분석 연결

### 6.1 기본 저장 구조

**IndexedDB를 실험 기록의 기준 저장소로 사용한다.** 측정 화면과 분석 화면은 동일 출처·브라우저 프로필에서 같은 실험 ID를 읽는다. `localStorage`는 마지막 실험 ID, 안내 선호 등 작은 설정에만 사용한다. IndexedDB는 비동기 구조화 데이터 저장과 트랜잭션을 제공한다. [S7], [S8]

| 저장 대상 | 내용 | 변경 원칙 |
|---|---|---|
| 실험 정보 | 실험 ID, 스키마 버전, 생성·갱신 시각, 열린/완료/중단 상태, 프로그램·센서 프로파일 | 같은 실험의 신원을 유지한다. |
| 원자료 | 불변 샘플 ID, 수신 시각, 연결 구간 ID, 수신한 온도·압력과 지원되는 추가 채널, 유효성 표시 | 추가 저장한다. 분석 조작으로 덮어쓰지 않는다. |
| 사건 | 가열 시작, 물 추가, 장치 변화, 수신 중단·복구, 점검 안내, 측정 종료 | 사용자 관찰과 자동 감지를 구분한다. |
| 분석 작업 | 선택·제외한 샘플 ID, 정렬·필터, 계산 열 정의, 그래프와 회귀 설정, 학생 메모 | 원자료와 별도로 수정·저장한다. |
| 환경 설정 | 안내 설정, 마지막 화면, 진단 설정 버전 | 앱의 이름 공간으로 구분한다. |

### 6.2 저장과 복원 동작

1. 새 실험에 ID를 만들고, 최초 유효값부터 준비 구간 자료로 기록한다.
2. 측정값은 작은 묶음으로 주기 저장한다. 초기 목표는 정상 동작 시 **1초 이내의 저장 대기열**이며, 저장 완료된 샘플과 아직 대기 중인 샘플을 구분한다.
3. 조작 사건과 분석 변경도 자동 저장한다. 상단에는 **저장 중 / 이 브라우저에 저장됨 / 저장 문제**를 표시한다.
4. **측정 마치기**를 누르면 입력을 마감하고 남은 자료·사건과 실험의 완료 상태를 같은 트랜잭션으로 저장한다. 성공하면 같은 ID의 분석 화면을 연다. 실패하면 저장 완료로 표시하지 않고 **저장 다시 시도 / 임시 자료로 분석**을 제공한다. 임시 분석은 기존 저장분과 같은 메모리의 미저장 자료를 함께 사용한다.
5. 새로고침 후에는 마지막 저장된 실험과 분석 작업을 다시 연다. 측정이 끝나지 않았던 실험은 **이어 측정 / 여기까지 분석**을 제공한다.
6. 재연결·다시 열린 측정은 새 연결 구간으로 기록한다. 수신되지 않은 구간을 0이나 보간값으로 채우지 않는다.

분석 진입을 위해 CSV 다운로드나 파일 재업로드를 요구하지 않는다. 기본 경로는 **브라우저에 기록을 저장한 뒤 곧바로 분석**이며, 저장 실패 시에는 아래의 임시 분석 경로를 사용한다. 파일 내보내기는 측정·분석 화면에서 언제든 사용할 수 있다.

### 6.3 오류와 저장 범위

- 저장 성공은 트랜잭션 완료 후 표시한다. 실패하면 이미 저장한 기록과 메모리의 미저장 자료를 유지하고 **저장 다시 시도 / 파일로 보관**을 제공한다.
- **임시 자료로 분석**을 선택하면 같은 실험 ID와 메모리 버퍼를 유지하고 **미저장 자료가 있음**을 계속 표시한다. 임시 분석의 작업 변경도 미저장으로 구분한다. 해당 화면 이동으로 미저장 자료를 버리지 않으며, 저장 재시도와 전체 실험 파일 내보내기를 계속 제공한다.
- 예상하지 못한 종료 시 마지막 미완료 저장분은 복구되지 않을 수 있다. 종료 시 이벤트만으로 저장을 보장하지 않는다.
- `navigator.storage.persist()`는 지원 환경에서 요청할 수 있으나 승인 여부와 관계없이 동작한다. 브라우저 데이터 삭제, 다른 프로필·기기, 다른 출처의 주소로 이동하면 동일 기록을 자동으로 읽는다고 약속하지 않는다. 전체 실험 파일로 옮길 수 있게 한다. [S7]
- 브라우저 저장은 클라우드 동기화가 아니다. 사용자 화면에는 **이 브라우저에 저장됨**으로 표시한다.
- 같은 실험에 대해 측정하는 탭은 하나로 제한한다. 두 번째 탭은 읽기 상태로 열고, 활성 측정 탭을 안내한다.

## 7 학생 주도 분석 작업 공간

### 7.1 화면 구성

| 영역 | 역할 |
|---|---|
| 상단 | 실험 이름, 저장 상태, 가져오기·내보내기 |
| 분석 도구줄 | 계산 열 추가, 그래프 만들기, 직선 맞추기, 분석 제외·복원, 되돌리기·다시 실행 |
| 자료 표 | 행 선택, 열 이름과 단위, 정렬·필터, 원자료와 계산 열 |
| 그래프 영역 | 선택한 자료·축으로 그린 그래프와 분석 결과 |
| 분석 도움말 | 첫 목표·화면 안내, 학생이 여는 단계별 목표 힌트와 수행 안내, 필요한 버튼에만 물음표 도움말 |

노트북에서는 표와 그래프를 좌우로 배치한다. 표는 첫 열·머리글을 고정하고 많은 행은 페이지 구분 없이 연속 스크롤로 읽고 화면 주변 행만 렌더링한다. 초기에는 실험당 하나의 작업 공간과 하나의 활성 그래프를 제공한다.

분석 첫 진입에는 §7.4의 목표·화면 안내를 보여 준다. 안내를 닫으면 원자료 표와 그래프를 사용할 수 있고, 아직 그래프가 없으면 축과 자료를 선택하는 간단한 안내를 표시한다. 회귀식과 결론을 자동으로 완성하지 않는다. 기본 축 후보는 온도와 압력이지만 학생이 변경하고 **그래프 만들기**로 적용한다. 저장된 작업을 다시 열 때에는 기존 표·그래프를 유지한다.

### 7.2 표와 범위 선택

- 클릭·범위 선택으로 행을 선택한다. 전체 선택과 선택 해제를 제공한다.
- **새 자료 보기**는 누른 시점까지의 새 원자료를 표에 불러올 뿐 선택·분석 범위·회귀를 바꾸지 않는다. M2의 **새 자료 적용** 버튼을 M3에서 이 이름과 역할로 전환한다.
- **선택 자료 적용**은 현재 선택한 ID로 분석 범위를 교체한다. **전체 자료 적용**은 표로 불러온 전체 ID를 적용하며 표 필터와 무관하다. 아직 표에 불러오지 않은 새 자료는 포함하지 않는다. **전체 선택**은 현재 필터에 해당하는 행을 선택하는 행동으로, 전체 자료 적용과 구분한다.
- 정렬·필터·체크만으로 기존 그래프·회귀는 바뀌지 않는다. 표의 선택 수·새 자료 수와 그래프의 적용 자료 수를 구분해 표시하고, 적용 전에 변경될 건수를 보여 준다. 적용 범위는 샘플 ID로 저장해 새로고침·추가 측정 후에도 복원한다. 행동별 계약은 [구현 설계 §7.1](DESIGN.md#71-표-상태와-적용-자료)을 따른다.
- 분석 범위는 **전체 자료 / 선택 자료**로 명시하고, 사용 점 수·시간 범위·제외 수를 함께 표시한다.
- 원자료 수치는 읽기 전용으로 보존한다. 학생은 메모·계산 열 이름과 분석 설정을 바꿀 수 있다.
- **분석에서 제외**는 샘플 ID와 선택적으로 입력한 사유를 기록하며, 여러 행에 같은 사유를 적용할 수 있다. **제외한 자료 n개 보기 → 선택 복원**으로 되돌리고 원자료는 유지한다. 복원한 행은 기존 적용 후보에 있을 때만 분석에 다시 참여한다. 새 범위 적용만으로 제외를 해제하지 않는다.
- 계산에 영향을 주는 변경을 적용하면 그래프를 갱신하고 기존 회귀·외삽 결과를 숨긴 뒤 **직선 다시 맞추기**를 표시한다. 적용 범위, 후보 안의 제외·복원, 계산 열의 연산·입력, 축에 사용하는 열이 바뀌는 경우다. 이름·표시 단위나 같은 축의 표시 범위만 바뀌면 기존 수치 결과를 유지한다. 이전 식을 새 자료의 결과로 표시하지 않는다.
- 데이터 부족·계산 불가 상태는 이유를 표시한다. 빈칸이나 잘못된 값을 0으로 계산하지 않는다.

### 7.3 초기 분석 도구

| 도구 | 쉬운 UI | 기록할 내용 |
|---|---|---|
| 계산 열 추가 | **절대온도**, **압력/절대온도**는 원클릭으로 추가한다. 직접 만들기는 `A+B`, `A−B`, `A×B`, `A÷B`, `Aᴮ` 중 연산을 먼저 고른 뒤 A·B 각각에 숫자 또는 자료 열을 지정한다. | 입력 열 ID, 연산·상수, 출력 이름·선택적 단위 |
| 그래프 만들기 | 현재 적용한 분석 범위를 확인하고 X·Y축을 선택한다. 기본은 산점도이고 시간축일 때 시간 변화선을 선택할 수 있다. | 대상 샘플 ID, 축·단위, 표시 설정 |
| 직선 맞추기 | 현재 그래프 자료에 선형회귀를 적용한다. | 대상 자료, 실제 축 이름을 포함한 식, 계수·R² |
| 직선 연장 | 회귀 후 학생이 켠다. 측정 범위 밖은 점선으로 구분한다. | 연장 범위와 절편 표시 설정 |
| 되돌리기·다시 실행 | 범위, 계산 열, 제외, 그래프 설정 변경을 되돌린다. | 현재 세션의 작업 이력 |

계산 열 하나는 하나의 연산을 맡는다. 직접 만들기는 같은 편집창에서 **연산 선택 → A·B 지정 → 결과 미리보기·이름 확인 → 열 추가** 순서로 조작한다. A·B는 각각 숫자 또는 원자료·기존 계산 열을 사용할 수 있다. 제곱은 `Aᴮ`에서 B를 `2`로 지정한다. 여러 계산은 계산 열을 이어서 구성하며 자유 수식 입력·괄호 편집·별도의 지수함수·로그는 초기 범위에 넣지 않는다. 이 순서는 계산 열 편집 안의 흐름이며 분석 도구 전체의 사용 순서를 강제하지 않는다.

**단위는 선택 입력**이다. 비워도 열 추가·그래프·내보내기를 사용할 수 있으며, 빈 단위를 무차원이라고 해석하거나 임의로 추정하지 않는다. 기본 계산은 이름·단위를 미리 채우지만 수정하거나 단위를 비울 수 있다. 직접 계산의 단위 자동 변환·차원 검사는 제공하지 않는다. 입력 열에 알려진 단위는 선택할 때 함께 보여 준다.

**절대온도**는 측정 온도에 `273.15`를 더하는 일반 계산 열이다. **압력/절대온도**는 해당 계산 정의의 열을 재사용하고, 없으면 절대온도 열과 비율 열을 한 번에 추가한다. 두 열 모두 표에서 확인·수정할 수 있으며 함께 추가한 작업은 한 번에 되돌린다. 이름·단위만 같은 다른 계산을 절대온도로 간주하지 않는다. 자유 계산에서 다른 열을 나누는 선택도 가능하지만, 앱이 이를 자동으로 기체 법칙 검증이라고 해석하지 않는다.

기본 계산과 직접 계산은 같은 계산·저장 기능을 사용한다. 열 머리글에서 같은 편집창을 다시 열어 수정하고, 적용 전에는 현재 자료 일부의 결과를 미리 본다. 숫자 입력 누락은 `0`으로 해석하지 않는다. 분모 0이나 지원 범위를 벗어난 거듭제곱 등은 해당 행에 이유가 있는 빈 결과로 표시한다. 세부 검증·저장 계약은 [구현 설계 §7.2](DESIGN.md#72-계산-열과-그래프)를 따른다.

사용 중인 계산 열은 삭제를 보류하고 참조하는 계산 열·그래프 축 등을 알려 준다. 사용하지 않는 열은 개별 삭제하고 되돌릴 수 있다. 프리셋으로 함께 추가한 작업의 되돌리기와 나중의 개별 삭제를 구분하며, 일반 삭제로 다른 열까지 자동 삭제하지 않는다.

회귀식 `y = ax + b`, R², x절편의 유효성은 각각 판단한다. 서로 다른 X값을 가진 유효 점이 2개 이상이면 회귀를 계산할 수 있다. 기울기 `a = 0`이어도 회귀선과 y절편 `b`는 표시할 수 있다. Y값이 모두 같아 R²를 정의할 수 없는 경우에는 그 이유만 따로 표시한다. R²는 직선성의 지표로 설명하고 사용한 점 수를 함께 보여준다.

절대영도 외삽 표시는 **섭씨온도 X축·압력 Y축의 회귀**에서 선택적으로 연다. `−b/a`를 측정 범위 밖의 추정으로 표시하고, 실제 측정 범위도 함께 남긴다. `a = 0`이면 x절편을 계산하지 않는다. 작은 기울기로 외삽이 불안정한 경우에도 회귀선·`a`·`b`는 유지하고 x절편 표시만 보류한다. 다른 축 조합에서는 그 축의 의미에 맞는 일반 회귀만 제공한다.

초기 그래프는 분석에 사용하는 측정점에 맞춰 축 범위를 자동 설정한다. **측정 범위 보기 / 직선 연장 보기**로 측정점 중심의 범위와 유효한 x절편까지 포함한 범위를 오가며, 보기 전환은 분석 자료·회귀를 바꾸지 않는다. 수동 범위 입력·드래그 확대·이동은 초기 필수 기능으로 추가하지 않는다. 세부 상태는 [구현 설계 §7.3](DESIGN.md#73-회귀-결과와-변경-처리)을 따른다.

### 7.4 힌트와 학생의 자유도

도움은 아래 네 종류로 구분한다. 첫 안내의 노출 여부를 성적·자료 상태·도구 사용 능력으로 판단하지 않는다.

| 종류 | 학생에게 제공할 내용 | 여는 방식 |
|---|---|---|
| 첫 목표·화면 안내 | 이곳에서 할 탐구 목표, 표·도구줄·그래프의 역할, 도움을 여는 위치 | 분석 첫 진입에 모두에게 자동 표시. 즉시 닫을 수 있고 **화면 안내**로 다시 열 수 있음 |
| 단계별 목표 힌트 | 지금 생각해 볼 질문과 얻으려는 결과 | 학생이 **목표 힌트**를 열고 원하는 단계를 선택 |
| 단계별 수행 안내 | 선택한 목표를 시도할 수 있는 구체적인 행동과 결과를 살펴보는 방법 | 각 단계의 **더 구체적인 도움이 필요해요** 버튼으로 펼침 |
| 버튼 도움말 | 해당 버튼이 하는 일이나 주의할 차이를 짧게 설명 | 이해가 어려울 수 있는 버튼 옆 작은 물음표의 툴팁 |

첫 안내의 목표 문구는 **“측정 자료를 근거로 온도와 압력의 관계를 설명해 보세요. 설명을 뒷받침할 그래프나 계산 결과를 만들고, 어떤 자료를 사용했는지 남겨 보세요.”**로 둔다. 정해진 비례 관계나 높은 R²를 얻는 것을 완료 목표로 제시하지 않는다. 화면 기능 안내는 표에서 자료를 살피고, 도구줄에서 계산·그래프를 만들며, 그래프에서 결과를 비교할 수 있다는 수준으로 짧게 설명한다. 조작 연습·퀴즈를 완료해야 닫히는 튜토리얼은 만들지 않는다.

목표 힌트는 아래 네 단계를 권장 순서로 제시하되, 어느 단계든 바로 열거나 건너뛸 수 있다. 목표 질문만 먼저 보이고 수행 안내는 닫혀 있다. 각 수행 안내는 따라 할 수 있는 한 가지 예이며 필수 분석 절차가 아니다.

| 단계 | 목표 힌트의 질문·목표 | 더 구체적인 수행 안내의 내용 |
|---|---|---|
| 1. 자료 살펴보기 | “어떤 조건에서 모은 자료인가요? 비교할 구간을 고르고 이유를 생각해 보세요.” | 표의 시각·구간과 조작 기록을 확인한다. 필요하면 시간축 그래프로 변화를 살피고 행 범위를 선택해 분석에 적용한다. 전체 자료도 선택 가능하며 자동으로 가열 구간을 골라 주지 않는다. |
| 2. 관계 찾기 | “온도가 달라질 때 압력은 어떻게 달라지나요? 그래프로 관계를 살펴보세요.” | 한 가지 시작 방법으로 X축 온도, Y축 압력을 골라 그래프를 만든다. 점의 전체 모양과 다른 경향을 보이는 구간을 관찰한다. 다른 축이나 범위로 다시 살펴볼 수도 있다. |
| 3. 계산으로 확인하기 | “눈으로 본 관계를 어떤 계산으로 확인할 수 있을까요? 함께 증가하는 것과 비례하는 것은 같을까요?” | **비율 살펴보기**에서는 절대온도와 압력/절대온도 열을 만들어 값의 변화를 비교한다. **직선으로 나타내기**에서는 직선 맞추기를 실행해 식·점의 분포·사용 범위를 함께 본다. 두 방법은 선택 가능한 예다. 직선 연장·절편 탐색은 별도로 펼치는 선택 탐구로 두고 측정 범위 밖의 추정임을 설명한다. |
| 4. 근거 정리하기 | “어떤 관계를 말할 수 있나요? 그 설명의 근거와 한계는 무엇인가요?” | 사용 구간과 그래프·계산 결과를 확인하고 메모에 관찰과 해석을 구분해 적는다. 제외한 자료가 있으면 이유를 남긴다. 조건 변화나 예상과 다른 결과도 설명에 포함하고, 필요한 그래프·자료를 내보낸다. |

버튼 도움말은 **선택 자료 적용**, **분석에서 제외**, **직선 연장**처럼 결과나 의미가 헷갈릴 수 있는 행동을 우선 대상으로 한다. 모든 버튼에 물음표를 붙이지 않으며 이름만 반복하는 설명이나 긴 수행 절차를 넣지 않는다. 클릭·키보드로도 열 수 있게 하고 필수 오류·비활성 이유를 툴팁 안에만 숨기지 않는다.

첫 안내를 닫거나 힌트를 읽은 횟수·답변 여부를 도구 사용의 조건으로 삼지 않는다. 힌트를 열거나 단계를 바꾸는 것만으로 자료·축·계산·회귀를 바꾸지 않으며 자동 완료·채점·강제 다음 단계 이동을 하지 않는다. 그래프에 맞는 자료를 자동으로 골라 주거나 학생의 결론을 자동 작성하지 않는다. 측정 단계의 점검 기록도 분석의 정답이나 자동 제외 기준으로 사용하지 않는다.

## 8 파일 내보내기와 가져오기

| 형식 | 내용 | 용도 |
|---|---|---|
| 전체 측정 CSV | 누른 시점까지 기록한 전체 원자료. 준비 구간·표에 아직 불러오지 않은 자료·분석에서 제외한 행 포함 | 스프레드시트에서 직접 분석 |
| 분석 자료 CSV | 학생이 적용한 후보에서 제외한 행을 뺀 범위와 내보내기로 선택한 계산 열. 현재 체크한 행과 구분 | 분석 결과 비교·재계산 |
| 전체 실험 JSON | 스키마 버전, 전체 원자료, 사건, 설정, 선택·적용 범위·제외·계산식·그래프 등 현재 분석 작업 상태 | 다른 기기·브라우저로 이동하거나 작업 복원 |
| 그래프 PNG | 현재 축·단위·범위가 표시된 그래프 | 활동지·보고서에 활용 |

**분석 자료 CSV**는 이전 명칭인 선택 자료 CSV를 대체한다. 계산 불가 값이 있어도 행은 유지하고 해당 값만 빈칸과 유효성·이유 표시로 내보낸다. 제외한 행은 이 파일에서 빼고 전체 실험 JSON에 보존한다. 출력 전에 자료 수와 제외 수를 확인할 수 있게 한다.

초기 CSV 가져오기는 **기존 bme280 CSV**와 **이 하위 프로젝트가 내보낸 CSV**를 지원한다. 기존 형식의 핵심 열은 `timestamp,temperature_c,humidity_pct,pressure_hpa`이다. 신규 형식에는 `sample_id`, `segment_id`, 경과 시간 등을 추가할 수 있으며 스키마를 명시한다. [R4]

- 열 이름으로 대응시키고 날짜·숫자·단위를 확인한다. 중복 시각도 행별 샘플 ID로 구분한다.
- CSV에 조작 기록·제외 사유가 없으면 가져온 뒤 비어 있는 상태로 표시한다. 과거 조작이나 가열 시작을 임의로 추정해 채우지 않는다.
- 분석 CSV의 계산 열은 이름·선택적 단위·유효성을 가진 숫자 자료 열로 가져온다. 그래프나 새 계산의 입력으로 사용할 수 있지만 계산식·의존 관계는 복원하지 않는다. 빈칸을 0으로 바꾸지 않으며, JSON은 거듭제곱·단위 없는 열을 포함한 계산 정의와 현재 작업 상태까지 복원한다.
- 임의 스프레드시트 파일과 자동 열 추론은 후속 범위로 둔다. 지원하지 않는 형식은 필요한 열 이름을 안내한다.
- JSON의 가져오기는 원자료와 현재 작업 상태의 복원을 확인한다. 충돌하는 실험 ID는 새 ID로 가져오고 출처 ID를 남긴다.
- 저장 파일명에는 실험명·날짜를 사용하고, 분석 자료 CSV는 전체 원자료와 구분되는 이름을 사용한다.
- 버튼 클릭이나 브라우저 다운로드 요청만으로 외부 파일 저장 완료를 확정하지 않는다. 브라우저 저장 완료와 파일 내보내기를 구분한다.

현재 범용 앱은 연결 UI가 전역 상태 초기화를 호출하는 구조다. 하위 프로젝트는 통신과 기록의 수명을 분리하고, 연결 해제로 실험 자료를 초기화하지 않는 정책을 적용한다. [`docs/AGENT.md`](../docs/AGENT.md)의 전체 로그와 표시 구간 분리 원칙을 이어받되, 재연결 시 기록 보존은 이 하위 프로젝트의 확정 결정 D4를 따른다. [R1], [R2]

기존 범용 앱·배선 안내의 동작을 유지하면서 실제 재사용이 필요한 부분부터 공통화한다. 3D 모델을 실험마다 별도 복제해 수정하지 않는다. 초기 연결에는 기존 뷰어를 독립 영역으로 사용하고 최소한의 가이드 어댑터를 추가할 수 있다. 현재 뷰어에 단계 제어 API가 이미 존재한다고 가정하지 않는다.

## 10 콘텐츠와 물리적 표현 원칙

- 준비 단계 바에서 원하는 단계로 바로 이동할 수 있다. 단계 이동은 확인 완료를 뜻하지 않으며 장치 연결과 수신 상태를 유지한다.
- 사용자 문구는 **마이크로비트 연결**, **실험 프로그램 넣기**, **용기 안 압력**, **저장된 실험 열기**처럼 실제 행동과 대상을 표현한다. 구현 방식·라이브러리 이름·빌드 표시는 학생 화면에서 사용하지 않는다.
- micro:bit·확장 보드·배터리·BMP280 센서와 배선을 **같은 밀폐 용기 안에 모두 넣는 구조**를 전체 그림에서 보여준다. micro:bit와 배터리는 바닥, 센서는 중간 높이의 공기 중에 놓고 벽·다른 부품과 직접 닿지 않도록 안내한다. USB는 밀폐 전에 분리하고 측정값은 Bluetooth로 전송한다. 뚜껑을 관통하는 선은 그리지 않는다. 물은 용기 밖 수조에만 두며 외부 고정은 후속 실험 계획을 반영한다. [R5], [S6]
- 기준 배선은 실제 사용할 모듈의 핀 이름과 내장 저항 구성을 확인한다. 3D 참고 모델에서 생략된 CSB·SDO 연결을 모든 모듈의 보편 규칙으로 적용하지 않는다.
- 온도는 측정값 `℃`와 계산한 절대온도 `K`를 구분한다. 압력 원자료는 절대압으로 유지하고, 변화량은 별도의 계산 열로 만든다.
- 짧은 표시값 안정은 관측 사실로 설명한다. 기체 전체의 열평형, 누설의 부재, 정확도 보증으로 확대하지 않는다.
- 센서 측정 범위와 용기의 사용 조건을 구분한다. BMP280의 300–1100 hPa는 센서 측정 범위이며, 용기의 안전 압력이나 허용 가열 조건이 아니다. [S6]
- 과거 실험의 특정 시작 온도·전도 시각·표본 수를 모든 사용자의 진행 조건으로 고정하지 않는다.
- 실제 예시 자료를 공개할 때 출처·조건·사건을 확인하고 예시임을 표시한다. 기존 `?mock=1` 난수는 화면 개발용으로 유지하고 실제 실험의 정상 반응 근거로 사용하지 않는다.

## 11 구현 순서와 완료 조건

아래 조건은 **앞으로 구현하면서 확인할 기준**이다. 이번 문서 작성으로 기능 구현이나 실기 검증이 완료된 것으로 처리하지 않는다.

| 단계 | 구현 내용 | 완료 조건 |
|---|---|---|
| M1 연결되는 뼈대 | 하위 앱 화면, 기존 3D 연결, 공식 라이브러리의 USB 설치, 기준 프로그램·수신 프로파일 확인, 저장소 스키마 | 앱 내부 버튼으로 기준 장치에 프로그램을 전송하고 새 측정값을 확인한다. 배터리 상태에서도 새 값이 들어온다. |
| M2 측정과 지속 저장 | 준비부터 측정 기록, 최소 안내, 사건, 수신 중단·복구, 저장 상태, 전체 CSV | 전체 자료가 보존되고, 연결·화면 변경으로 사라지지 않는다. 측정 마침 후 같은 실험을 분석 화면에서 읽고 전체 CSV로도 내보낸다. |
| M3 자유 분석 | 표 갱신·분석 범위 적용과 복원, 계산 열, 그래프·회귀·연장, 제외·복원, 힌트, 나머지 파일 입출력 | 학생이 힌트 없이도 도구를 임의 순서로 사용할 수 있다. 추가 측정·표 갱신으로 기존 분석이 바뀌지 않고 저장된 범위를 다시 연다. |
| M4 기본 점검과 흐름 확인 | 누설 의심 규칙, 보류·해제·근거 기록, 처음 준비부터 외부 CSV 분석까지 확인 | 규칙이 조건 부족·공백·냉각을 구분하고 원자료를 변경하지 않는다. 실제 자료 검토로 오경보를 확인한다. |

### 필요한 범위의 검증

- **공식 전송 경로:** 앱 내부 버튼 → 최초 USB 선택 → 자동 HEX 전송 → 완료 → Bluetooth·배터리 수신을 기준 실물에서 확인한다. 취소·실패·진행률만으로 완료를 오인하지 않는 경계는 자동 검사한다.
- **기록 연속성:** 실제 간격이 일정하지 않은 자료, 수신 중단·재연결, 새로고침, 저장 실패를 확인한다. 저장된 원자료·분석 ID의 대응을 검토한다.
- **점검 규칙:** 알려진 정상 비례 합성자료, 압력 반응이 작은 합성자료, 온도 변화 부족·냉각·통신 공백을 사용해 규칙의 동작을 확인한다. 합성자료 검증을 실제 누설 검출 성능으로 해석하지 않는다.
- **분석 계산:** 결과를 아는 자료로 계산 열과 회귀를 확인하고, 상수 X·분모 0·거듭제곱의 계산 불가·결측치 처리를 확인한다. 기본 계산과 직접 계산의 결과 일치, 연관 열 재사용·수정·되돌리기, 단위 없는 열의 저장·내보내기를 확인한다. 정렬·필터·제외·복원 후 대상 샘플이 유지되는지 살핀다.
- **파일 복원:** 내보낸 JSON을 다시 열어 원자료·사건·현재 분석 상태가 일치하는지 확인한다. CSV는 실제 스프레드시트에서 열 이름·단위·숫자·시각을 확인한다.
- **기존 기능:** 수정한 공통 모듈을 사용하는 범용 앱과 배선 안내에 한해 영향 확인을 수행한다. 문서만 바꾼 단계에서 앱 전체 테스트를 반복하지 않는다.

## 12 확인할 조건과 후속 확장

### 구현과 함께 확인할 항목

| 항목 | 확인 목적 | 미확정일 때의 처리 |
|---|---|---|
| 기준 BMP280 보드·배선·프로그램 | 안내와 실제 연결의 일치 | 기준 조합을 확인하기 전 해당 조합을 작동 검증 완료로 표시하지 않는다. |
| 앱 내부 USB 설치와 실패 경로 | 실제 사용 화면에 맞춘 안내 | 공식 API 완료와 센서 동작 확인을 구분하고 실물 결과를 별도로 기록한다. |
| 용기와 가열 조건 | 제품 조건에 맞는 실험 운영 | 가열 상한·물 투입량·압력 중단 기준을 임의 숫자로 제시하지 않는다. |
| 추가 실험의 변화 양상 | 누설 의심 휴리스틱의 과도한 안내 확인 | 계산 모듈은 구현하되 설정을 미검증으로 관리하고 현장 적용 전에 재생·실기 검토한다. |
| 학교의 이용 기기 | 실제 연결·표 조작·파일 저장 가능 여부 | 기준 환경을 먼저 지원하고 나머지는 안내·분석 이용 가능 범위와 구분한다. |

초기 버전의 목적은 연결되는 기능 모듈을 완성하는 것이다. 세밀한 수업 대본·자동 평형 판정·정밀 오차 보정은 실제 자료를 바탕으로 후속 개선한다.

### 중급자 모드로 확장하는 기준

측정·저장·분석·점검 엔진은 공통으로 사용한다. 중급자 모드에서는 준비 설명을 선택적으로 열고, 측정 절차와 분석 설정의 선택 범위를 넓힌다. 초보자 분석 화면도 현재 기획부터 자유 작업 공간이므로, 중급자용 분석 앱을 별도로 다시 만들지 않는다.
