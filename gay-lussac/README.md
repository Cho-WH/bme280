# 게이뤼삭 실험

**기체의 온도와 압력**을 측정하는 전용 실험 앱의 하위 프로젝트입니다. 3D 장치 준비, 공식 도구의 USB 프로그램 전송, 최소 측정 안내와 실시간 점검, 브라우저 저장, 학생 주도 분석을 연결합니다.

> [!NOTE]
> 현재는 **초보자 모드 초기 버전 기획 단계**입니다. 구현 범위와 완료 조건은 기획안에서 확인할 수 있습니다.

## 기획안

### [초보자 모드 초기 버전 기획안](PLAN.md)

| 확정 방향 | 내용 |
|---|---|
| 장치 준비 | 기존 BMP280 배선 3D 안내와 공식 HEX 전송 도구 활용 |
| 측정 | 최소 안내와 수신·누설 의심 추세 점검을 모듈화 |
| 저장 | IndexedDB에 원자료·사건·분석 작업을 보존 |
| 분석 | 스프레드시트와 비슷한 자유 작업 공간, 쉬운 분석 도구, 선택적 힌트 |
| 외부 활용 | CSV·전체 실험 파일·그래프 내보내기 |

분석 화면은 초보자 모드에서도 학생이 순서와 자료를 직접 선택합니다. 준비·측정 안내와 분석 도구를 분리해 이후 중급자 모드에도 같은 기능을 활용합니다.

## 기존 도구

- [범용 측정 도구](https://cho-wh.github.io/bme280/)
- [BMP280 배선 3D 안내](https://cho-wh.github.io/bme280/bmp280-wiring/)
- [공식 micro:bit HEX 전송 도구](https://microbit.org/tools/webusb-hex-download-tool/)

구현 후 실행 경로는 `/bme280/gay-lussac/`를 사용합니다. 현재 이 폴더에는 기획 문서를 보관합니다.
