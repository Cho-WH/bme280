# 게이뤼삭 실험

**기체의 온도와 압력**을 측정하는 전용 앱입니다. 3D 장치 준비, 공식 도구의 USB 프로그램 전송, 측정·브라우저 저장, 학생 주도 분석을 연결합니다.

## 현재 구현 상태

2026-10-12 기준입니다. 이 문서를 구현·검증 현황의 기준으로 사용하고, 설계 문서에는 동작 계약과 후속 기능을 남깁니다.

| 단계 | 구현한 범위 | 남은 범위 |
|---|---|---|
| M1 준비·연결 | 기존 3D 안내·배선표, 공식 USB 전송, BLE 연결·배터리 수신 확인 | 다른 장치 조합 검증 |
| M2 측정·저장 | 원자료·사건 기록, 시간 그래프, 일시정지·재개·추가 측정, 자동 저장·복원·단일 작성자, 전체 CSV | 일시정지·추가 측정의 실물 확인, 장시간·가열 실험 |
| M3 표·계산 열·그래프 | 자료 선택·열 필터·정렬, 사용/제외·사유, 기본/지정 분석 대상, 계산 열 추가·편집·삭제, 되돌리기·다시 실행, 세 가지 보기·축 선택·산점도·시간 변화선, 추세선 토글·자동 회귀 갱신·직선 연장, 작업 저장, 전체/분석 CSV·JSON·PNG 다운로드, CSV·JSON 가져오기, 조작 메모 편집 | 도움말 |
| M4 점검·사용성 | 수신 중단 등 기본 수신 점검은 구현 | 누설 의심 추세, 실제 학생·교사 사용성, 전체 실험 흐름 검증 |

현재 변경은 로컬 작업이며 배포하지 않았습니다. 설계에 포함된 후속 기능을 구현 완료로 간주하지 않습니다.

## 실행과 검사

저장소 루트에서 실행합니다. 별도 패키지 설치·빌드는 없습니다.

```powershell
node gay-lussac/dev/serve.mjs 8765
node --test gay-lussac/tests/*.test.mjs
```

- [로컬 앱](http://127.0.0.1:8765/gay-lussac/): 노트북 Chrome·Edge에서 사용합니다. 포트를 생략하면 서버 기본값은 8766이며 `Ctrl+C`로 종료합니다.
- [브라우저 저장 경계 검사](http://127.0.0.1:8765/gay-lussac/tests/browser.html): 실제 IndexedDB·Web Locks를 확인합니다. 검사 DB는 `bme280.gay-lussac.tests`입니다. 별도 버튼을 눌러야 앱 DB에 재생 실험을 추가합니다.
- 서버는 `127.0.0.1`에서 저장소 루트를 제공합니다. 상위 BLE·3D·차트·HEX 자원을 함께 사용하므로 HTML 파일을 직접 열어 실행하지 않습니다. 배포 경로는 `/bme280/gay-lussac/`입니다.

## 자료 분석의 동작

| 조작 | 현재 동작 |
|---|---|
| 전체·범위 체크 | 헤더 체크는 필터에 맞는 전체 행을 선택·해제합니다. ID 범위 확인은 현재 필터 안에서 양 끝을 포함한 범위로 체크를 교체합니다. Shift 체크는 표시 순서를 따릅니다. |
| 사용·제외 | 체크한 행에 적용하고 체크를 비웁니다. 제외 사유는 표 아래에서 입력하며 기존 사유는 유지합니다. 원자료 수치는 바꾸지 않습니다. |
| 기본·지정 분석 | 기본은 불러온 전체 사용 자료입니다. ‘선택한 자료만 분석’은 명령 시점의 체크 ID를 저장합니다. 이후 체크·필터는 분석 대상을 바꾸지 않습니다. |
| 새 자료 보기 | 새 수신은 건수로 알리고 명시적으로 불러옵니다. 기본 분석은 확장하고 지정 분석은 지정 ID를 유지합니다. |
| 열 필터 | 숫자 범위, 사용/제외·유효성 목록, 사유 문자열을 조합합니다. 수신 시각은 날짜 없이 시:분:초.밀리초로 입력하며 자정 경계를 지원합니다. 한 열만 해제할 수 있고 필터 변경은 체크를 비웁니다. |
| 되돌리기·다시 실행 | 지정 분석·사용/제외·계산 열·그래프·추세선 설정을 복원합니다. 현재 필터·표 범위는 유지하고 필터에서 숨겨지는 체크는 제거합니다. 이력은 열린 작업 동안만 유지합니다. |
| 저장·스크롤 | 체크·정렬·필터·분석 대상·제외를 저장합니다. 스크롤 위치는 화면에서만 유지하며 저장 상태를 바꾸지 않습니다. 다시 열면 표 맨 위에서 시작합니다. |
| 화면 | 32px 가상 행, 제목 오른쪽의 작은 자료 수 표시, 열 헤더 필터, 기호형 이력 버튼을 사용합니다. 공통 버튼은 ‘다운로드 → 추가 측정 → 새 실험’이며 다운로드만 강조색입니다. |
| 계산 열 | 마지막 자료 열 헤더 오른쪽의 **+ 계산 열**에서 절대온도·압력/절대온도·직접 만들기를 선택합니다. 템플릿도 편집창을 거쳐 확인해야 추가되며 입력을 바꾸면 식 기반 이름으로 전환됩니다. 사칙연산·거듭제곱, 온도·압력·가져온 숫자 열·기존 계산 열·숫자를 사용하며 단위는 선택 사항입니다. 표 맨 오른쪽에 추가하고 제외 행에도 결과를 표시합니다. |
| 계산 열 편집·삭제 | 헤더 `⋯` 메뉴를 사용합니다. 헤더 클릭은 정렬, 필터 기호는 숫자 범위 필터입니다. 참조 중인 열은 삭제를 보류하며 추가·수정·삭제는 기존 이력으로 복원합니다. 계산 불가 셀은 `—`를 눌러 이유를 확인합니다. |
| 표 / 표·그래프 / 그래프 | 표는 전체 열, 동시 보기는 체크·ID·현재 X/Y축 열·분석 여부만 표시합니다. 전체 표의 열 너비를 재사용하며 좌우 배치의 표 영역은 필요한 폭만 차지합니다. 같은 축은 한 번만 표시하고 축을 적용한 뒤 열을 갱신합니다. 좁은 화면에서는 압축 표 아래에 그래프를 배치합니다. 보기 전환은 선택·분석 대상·저장 상태를 바꾸지 않으며 다시 열 때는 표 보기로 시작합니다. |
| 그래프 | 온도·압력·가져온 숫자 열·계산 열과 X축 수신 시각을 선택하고 만들기/적용으로 확정합니다. 표 필터와 무관하게 현재 분석 대상을 그립니다. 제외점은 회색 ×로 남기고 클릭하면 표와 같은 체크 상태로 선택·해제합니다. 시간 변화선의 공백 연결은 보기 설정이며 제외·계산 불가·시각 역행은 연결하지 않습니다. 축·표시 설정은 저장하고 이력으로 복원합니다. |
| 추세선 표시 | 그래프 축 설정 아래의 토글로 켜거나 끕니다. 현재 분석 대상의 사용 상태인 유효점으로 선형회귀하고, 실제 입력 변경 시 자동 갱신합니다. 체크·필터·정렬은 수치 결과를 바꾸지 않습니다. 식·R²·사용 점 수는 고정 높이 영역에 표시하며 수신 시각 축의 식은 첫 사용점 기준 경과 시간(초)을 사용합니다. 켜짐 상태·계산 불가 후 회복·재열기와 이력 복원을 지원합니다. |
| 직선 연장 | 추세선이 켜져 있을 때 측정 범위/직선 연장으로 전환합니다. 측정 범위 밖은 점선이며 x절편을 함께 표시합니다. 섭씨온도–압력 조합만 절대영도 추정으로 표시합니다. R²나 x절편이 계산 불가여도 유효한 회귀선은 유지합니다. 기존 사용/제외 기능은 유지하며 회귀 전용 선택·제외 기능은 추가하지 않습니다. |
| 파일 다운로드 | 다운로드 메뉴에서 전체 원자료 CSV·분석 자료 CSV·그래프 PNG·전체 실험 JSON을 선택합니다. 분석 CSV는 출력 행 수를 확인하고 계산 열을 고릅니다. PNG는 현재 적용한 축·단위·표시 범위·추세선·회귀식·R²를 흰 배경에 담으며 표 보기에서도 내보낼 수 있습니다. |
| 실험 파일 열기 | 시작 화면의 **실험 파일 열기 (CSV·JSON)**에서 50MB 이하 파일을 선택합니다. CSV는 기존 bme280 또는 이 앱이 내보낸 형식을 새 실험으로 열고, JSON은 전체 실험을 복원합니다. 형식·ID·숫자·작업 참조를 검증한 뒤 원자료·사건·분석 작업을 함께 저장합니다. 같은 ID가 있으면 새 ID를 만들어 기존 실험을 보존하고, 추세선은 복원한 자료로 다시 계산합니다. 측정과 미저장 작업이 남아 있으면 전환을 보류합니다. |
| CSV의 숫자 열 | 가져온 습도·계산 결과는 표 오른쪽에 고정 자료 열로 표시합니다. 기존 필터·정렬·체크·사용/제외·계산 입력·그래프 축을 그대로 사용하고 새 계산 열은 그 뒤에 추가합니다. 빈칸은 0으로 바꾸지 않으며 없는 계산식·사건·제외 상태를 추정하지 않습니다. 잘못된 행은 행 번호와 오류를 표시하고 파일 전체를 거부합니다. |
| 조작 메모 | 측정·분석 화면의 **조작·수신 기록**에서 사용자 기록의 메모를 추가·수정·비우기할 수 있습니다. 500자 이내의 최신 내용을 자동 저장하고 측정 종료 후에도 수정합니다. 취소하면 초안을 버립니다. 사건 시각·종류·조건과 자동 기록·측정값은 유지하며 다시 열기와 전체 실험 JSON에 반영합니다. 읽기 전용 실험에는 편집 버튼을 표시하지 않습니다. |
| 힌트 | 현재 표시하지 않습니다. 기존 문구는 `analysis/hints.js`에 보관하며 현재 동작 설명으로 자동 재사용하지 않습니다. |

현재 장치 프로파일에는 시각 필드가 없으므로 표·시각 필터는 앱이 기록한 로컬 수신 시각을 사용합니다. 원자료 UTC와 CSV 원값은 유지합니다. 상세 계약은 [DESIGN §7.1](DESIGN.md#71-표-상태와-적용-자료), 모듈 책임은 [ARCHITECTURE](ARCHITECTURE.md)를 따릅니다.

구간 번호·구간별 경과시간·시작/종료 기록과 표의 구간 열·필터를 제거했습니다. 측정 그래프는 수신 시각의 5초 이상 공백에서 선을 끊습니다. 분석 그래프에서는 X축을 수신 시각으로 선택한 시간 변화선에서 공백 연결 여부를 선택합니다. 기존 원자료는 보존하고 옛 구간 정보는 무시합니다.

실물 확인 HEX는 `firmware/bme_1.2.hex`, SHA-256은 `435fb8f8d160da517f3924d34cb22294a5d9e3c2aadca6bb4f5b305346e97186`입니다. 기록 ID는 `aa96af28-274a-41e8-9714-f9afba1cb1c3`입니다. 당시 구현의 CSV를 PowerShell `Import-Csv`로 읽어 276행의 ID 연속성·재연결 전후 자료·UTF-8 BOM·압력 원값을 확인했습니다. 두 차례 실제 수신 시간의 합은 약 51초입니다.

USB 분리는 사용자 확인에 근거하며 앱이 전원 종류를 자동 감지하지 않습니다. 센서·확장 보드의 정확한 제품명은 기록되지 않았습니다. 최초 연결·재연결 중 일시 단절을 관찰했으나 원인을 특정하지 않았습니다. `communication-verified`는 설치·수신·배터리 동작 확인이며 센서 정확도나 모든 보드 조합을 보증하지 않습니다. 기존 HEX 계산식 수정은 보류 상태입니다.

**미확인:** 구간 기록 제거 후 실물 재수신, 물 가열·장시간 안정성, Excel 화면에서 CSV 열기, 새 일시정지·추가 측정 기능의 실물 사용, 실제 센서가 추가 수신 중인 M3 화면, 실제 학생·교사 사용성. 새 자료 반영 규칙은 자동 검사로 확인했습니다.

실물 재현은 **배선 확인 → 앱의 USB 설치 → 새 유효값 3개·1초 수신 → 배터리 연결·USB 분리 확인 → 이후 새 값 재확인** 순서입니다. 장치 조합이 달라지면 센서·보드·브라우저·HEX 해시와 결과를 함께 기록합니다.

## 저장 범위

- 열린 실험의 원자료·사건·Workspace는 RunStore가 소유하고 Repository가 IndexedDB에 기록합니다. 측정 화면의 최대 60초·6,000점 캐시는 표시용이며 원자료 보존량과 무관합니다.
- 약 1초 묶음 저장을 사용합니다. 실패한 묶음은 동일 내용부터 재시도하며 비정상 종료 복원은 마지막 완료 트랜잭션까지입니다. 오류 중에는 탭을 유지하고 다시 저장하거나 다운로드로 보관합니다.
- 전체 CSV는 준비 구간·범위 밖 값·제외 행·아직 표에 불러오지 않은 자료를 포함한 모든 원자료입니다. 분석 CSV는 적용 후보에서 제외한 행을 빼고 선택한 계산 열과 유효성·이유를 덧붙입니다. 표 필터·정렬·현재 체크는 출력 범위를 바꾸지 않습니다.
- 전체 JSON은 저장 대기 자료까지 포함한 원자료·사건·현재 Workspace를 담습니다. CSV는 파일에 담긴 행·수치만 새 실험으로 가져옵니다. 계산식·제외 사유까지 복원하려면 JSON을 사용합니다. JSON의 미완료 상태는 유지하되 자동 측정·자동 사건 기록은 시작하지 않습니다.
- CSV·재생 자료에는 실제 BLE 입력을 덧붙이지 않으며 추가 측정도 비활성화합니다. 실제 장치 기록은 새 실험에서 시작합니다. 재생 검증 자료는 `source=replay`로 구분합니다.
