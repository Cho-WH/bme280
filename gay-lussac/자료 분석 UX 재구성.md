# 자료 분석 UX 재구성

작성일: 2026-10-13 · 자료 분석 UX 구현 기준

학생은 자료를 살펴보고 자유롭게 분석한 뒤, 선택한 그래프를 근거로 자신의 설명을 작성한다. 현재 구현·검증 현황은 [README](README.md), 저장과 계산의 계약은 [DESIGN](DESIGN.md), 모듈 책임은 [ARCHITECTURE](ARCHITECTURE.md)를 따른다.

## 1. 세 화면의 역할

| 메뉴 | 학생의 활동 | 주요 요소 |
|---|---|---|
| 원 자료 보기 | 실험 전체의 변화를 살펴보고 분석 범위를 정한다 | 왼쪽 온도·오른쪽 기압 축 시간 그래프, 동시 시점 읽기, 구간 손잡이, 접힌 표 |
| 관계 그래프 | 축·계산 열·제외·추세선을 자유롭게 조작한다 | 큰 그래프, 즉시 변경되는 축, 옆 도구 영역, 펼칠 수 있는 표 |
| 결과 해석 | 선택한 근거로 발견한 관계를 설명한다 | 가져온 그래프 하나, 세 질문, 자동 저장, 탐구 기록 인쇄 |

메뉴는 처음부터 자유롭게 이동할 수 있다. 구간 선택·추세선·글 작성 여부를 다음 화면의 진입 조건으로 삼지 않는다. 원 자료 보기로 시작하며 표는 접혀 있다.

## 2. 원 자료 보기와 구간

시간을 가로축으로 온도와 기압을 겹쳐 표시한다. 온도는 왼쪽 세로축, 기압은 오른쪽 세로축을 사용한다. 세로 커서에서 가장 가까운 실제 측정 시점의 두 값을 함께 읽는다. 보간한 값을 측정값처럼 보여 주지 않는다.

주요 행동은 **전체 자료로 관계 보기**와 **구간 골라 분석하기**다. 후자를 누르면 양 끝 손잡이와 시작·끝 경과시간 입력이 나타난다. 선택 밖은 흐리게 표시하고 자료 수를 즉시 보여 준다.

- 손잡이와 시간 입력은 같은 초안이다. 방향키·Home·End도 지원한다.
- 전체 구간은 초안을 초기화한다. 취소는 확정 범위를 유지한다.
- **이 구간으로 분석**에서 한 번 확정·저장하고 관계 그래프로 이동한다.
- 구간 수정은 이전 위치를 다시 보여 준다. 이전 비연속 ID 범위는 새 구간 확정 전까지 보존한다.
- 실제 수신 시각으로 판단한다. 날짜가 바뀌거나 동일 시각 자료가 있어도 표의 날짜 없는 시각 필터와 혼동하지 않는다.
- 지정 범위에 새 수신을 자동 포함하지 않는다. 원자료와 확정 ID는 보존한다.
- 좋은 구간을 자동 선택하지 않는다.

구간 메타데이터는 `analysisRange: { startAt, endAt, throughSampleId }`다. `appliedIds`와 함께 변경하며 JSON에서 정확한 ID 대응을 검증한다.

## 3. 관계 그래프

기본 축은 온도–압력이다. 학생은 원자료·가져온 숫자 열·계산 열을 자유롭게 고른다. 축 변경은 즉시 반영하며 별도 적용 버튼을 두지 않는다.

그래프 옆에 추세선·추세선 연장·계산 열 추가·표시 설정을 모은다. 추세선과 연장은 처음 꺼져 있으며 학생이 켠다. 그래프 아래에 회귀 자료 수·기울기·y절편·R²를 표시하고, 식·x절편·수치의 설명은 상세 보기로 제공한다.

관계 그래프는 표+그래프를 기본으로 연다. 넓은 화면에서 표는 왼쪽, 좁은 화면에서는 아래에 놓는다. 압축 표는 현재 축 열과 방금 만든 계산 열을 보여 주며 기본·계산·가져온 숫자 열에 같은 너비 규칙을 적용하고 필터 아이콘을 생략한다. 상단에는 **표 / 표 & 그래프 / 그래프** 연결형 선택창을 크게 배치하고 선택 음영이 미끄러지듯 이동한다. 표는 그래프 없이 모든 열·필터를 갖춘 전체 너비 표, 표 & 그래프는 함께 보기, 그래프는 그래프만 표시한다. 분석 자료 수와 시간 구간·구간 수정·이력은 오른쪽에 모은다. 기존 전체 열·표 접기·표 보기 버튼은 제거한다. 적용한 필터는 보기 전환에도 유지하며 압축 표에는 적용 건수와 상단 표 보기에서 확인하라는 문구만 표시한다. 같은 가상 표를 재사용한다.

계산 열은 기존 편집기를 사용한다. 저장 전에 실제 입력 A/B와 결과를 병기하고, 열을 만든 뒤에도 그래프 축은 유지한다. 새 계산 열은 표에서 바로 확인할 수 있다.

그래프 하단의 **이 그래프로 결과 해석하기**로 현재 그래프와 분석 조건을 근거로 가져온다. 그래프 이미지·분석 CSV 저장도 관계 그래프에서 제공한다.

## 4. 분석 상태의 일치

| 표시 | 의미 |
|---|---|
| 분석 포함 | 확정 후보 안에서 제외되지 않은 자료 |
| 제외 | 확정 후보 안에서 학생이 제외한 자료 |
| 범위 밖 | 확정 후보 밖의 자료. 저장된 제외 여부와 무관하게 우선 표시 |

표의 체크는 일괄 조작 대상이며 분석 범위가 아니다. 체크가 있을 때만 표 아래에 제외·다시 포함 작업 막대를 표시한다. 하단 자리는 항상 확보하므로 선택·해제로 표와 체크박스가 움직이지 않으며 마지막 행을 가리지 않는다. 제외 사유는 분석에서 제외 버튼을 누르면 작은 팝업에서 선택적으로 입력하고, 빈칸으로도 제외할 수 있다. 점·행 클릭은 표 하단의 고정 정보 카드와 행 강조를 연결하며 체크를 바꾸지 않는다. 그래프만 보기에서는 카드가 그래프 아래에 놓인다. 미선택 상태에도 같은 높이를 확보하여 표·그래프 위치가 유지되고 자동 스크롤·초점 이동을 하지 않는다. 같은 자료 재클릭, 빈 그래프 클릭, Esc 또는 선택 해제로 닫는다. 개별 제외는 기존 사유 팝업을 재사용한다.

제외한 점은 옅은 빈 원으로 남고 회귀는 즉시 갱신한다. 제외 사유는 선택이며 제외 직후 되돌리기를 제공한다. 현재 분석의 표·그래프·CSV는 같은 후보와 제외 정의를 사용한다. 값이 없는 자료는 포함 수와 별도로 그래프·회귀에서 빠진 개수를 표시한다.

결과 해석의 자료 수는 **가져온 근거**를 기준으로 한다. 현재 분석의 상태 막대를 결과 해석에 섞어 보여 주지 않는다.

## 5. 결과 해석: 근거와 글

결과 해석은 학생이 가져온 그래프의 축과 표시 상태를 따른다. 별도의 축 선택·추세선 토글·제외 도구를 두지 않는다. 근거를 수정하려면 관계 그래프로 돌아간다.

### 화면 구성

왼쪽 근거 카드에는 실험 이름, 축·단위, 그래프, 구간·포함/제외 수, 접힌 추세선 수치를 둔다. 넓은 화면에서는 글을 쓰는 동안 근거 카드를 화면에 유지하고, 작은 화면에서는 위아래로 배치한다.

오른쪽에는 다음 세 작성 칸을 둔다.

| 항목 | 질문 |
|---|---|
| 발견한 관계 | 두 축의 값 사이에서 어떤 관계를 발견했나요? |
| 판단한 근거 | 그래프의 어떤 모습이나 수치가 그 설명을 뒷받침하나요? |
| 해석과 한계 | 이 자료로 설명하기 어려운 점이나 다시 확인하고 싶은 점은 무엇인가요? |

각 칸은 빈 상태로 시작하며 1,200자 이내의 일반 텍스트를 저장한다. 학생의 글을 자동 작성·채점하지 않는다. 빈칸이 있어도 이동·저장·인쇄할 수 있다. 글 입력은 회귀 입력이나 분석 되돌리기 이력에 포함하지 않는다.

### 조건에 맞는 보조 질문

- 제외 자료가 있으면 판단한 근거 아래에서 기존 제외 사유를 펼쳐 볼 수 있다.
- 계산 열을 축으로 썼으면 사용한 계산식과 관련 의존 열을 보여 주고 물리량을 바꾼 이유를 묻는다. 이름만으로 계산 의미를 추정하지 않는다.
- 직선을 연장했다면 해석과 한계 아래에서 측정 구간과 연장 구간의 차이를 묻는다.
- 섭씨온도–압력 축에서 유효한 x절편이 있을 때만 절대영도 추정에 관한 접힌 설명을 제공한다.
- 추세선을 사용하지 않은 그래프도 유효한 근거다.

### 이동과 교체

| 행동 | 동작 |
|---|---|
| 첫 결과 해석 진입 | 유효한 그래프와 쓰기 권한이 있으면 현재 관계 그래프를 가져온다 |
| 그래프가 없는 상태 | 안내와 관계 그래프 진입 버튼 표시. 글은 작성할 수 있다 |
| 관계 그래프의 가져오기 버튼 | 현재 근거를 교체하고 결과 해석으로 이동. 기존 글 유지 |
| 다시 분석한 뒤 결과 해석 메뉴로 이동 | 이전 근거·글 유지. 달라진 분석에 대한 안내와 현재 그래프로 바꾸기 표시 |
| 현재 그래프로 바꾸기 | 근거만 교체하고 설명 재확인 안내 |
| 표 정렬·체크·필터 변경 | 근거 변경으로 판단하지 않음 |
| 지정 범위 밖 자료 추가·제외, 축과 무관한 계산 열 추가 | 근거 변경으로 판단하지 않음 |
| 읽기 전용 | 저장된 글·근거 조회와 인쇄·내보내기만 허용 |

원자료는 추가 저장되며, 근거 그래프는 확정한 ID와 당시 계산식으로 재현한다. 현재 계산식을 편집·삭제하거나 분석 이력을 되돌려도 기존 근거와 글을 바꾸지 않는다.

## 6. 저장과 인쇄

Workspace의 선택적 `reflection` 필드에 근거 하나와 세 답변을 저장한다.

- `evidence`: 자료 경계, 후보 ID, 범위, 제외·사유, 축이 사용하는 계산식과 의존식, 그래프 정의, 추세선 켜짐.
- `answers`: observation, reasoning, limitations.
- 원자료·차트 인스턴스·계산 결과·PNG를 중복 저장하지 않는다. 기존 계산·회귀 엔진으로 재현한다.
- 글 입력은 즉시 RunStore에 전달하고 기존 자동 저장 경로를 사용한다. 저장 대기·완료·실패·읽기 전용을 구분한다.
- JSON에 근거와 글을 포함한다. 재열기·가져오기는 자료 ID·계산 참조·범위·글 길이를 검증한다.
- 기존 파일에 reflection이 없으면 빈 기록으로 연다. 옛 결과 해석 토글을 학생의 근거나 글로 변환하지 않는다.

**탐구 기록 인쇄·PDF**는 실험 이름, 가져온 그래프와 조건, 세 답변으로 인쇄용 문서를 만든다. 긴 글은 다음 페이지로 이어지며 빈 답변도 보존한다. PDF 저장은 브라우저 인쇄 대화상자를 사용한다. **이어하기용 파일 저장**은 기존 전체 실험 JSON이다.

상단 다운로드 메뉴의 PNG는 결과 해석에서 보관한 근거를 출력한다. 분석 CSV는 관계 그래프의 현재 분석 범위를 따른다.

제목은 한국어로 표시하며 같은 의미의 영어 소제목과 장식용 배지·기호를 덧붙이지 않는다. 결과 해석의 근거·작성 카드는 얇은 테두리와 12px 모서리로 구분하고 그림자는 사용하지 않는다. 질문, 노트 줄, 가져온 근거의 상태 표시는 유지한다.

새 차트·통계·PDF 라이브러리는 추가하지 않는다. 화면 이동과 카드 등장에는 짧은 전환을 적용하고 사용자의 동작 줄이기 설정을 따른다.

## 8. 확인 기준과 범위

근거 가져오기 → 세 답변 작성 → 축/구간/제외/계산 변경 → 이전 근거 유지 → 명시적 교체 → 글 유지 → 재열기·JSON 복원 → 인쇄 기록 일치를 확인한다. 없는 ID·잘못된 계산 참조·과도한 글은 가져오기 전에 거부한다. 원자료 불변, 읽기 전용, 저장 실패와 분석 되돌리기도 확인한다.

여러 그래프 모으기, 보고서 버전 관리, 자동 결론·채점, 교사 제출·계정, 자유 수식 고급 편집기는 현재 범위에 넣지 않는다.
